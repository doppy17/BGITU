# Учебный план: сетка, штрих, палитра отрезков

Файлы: `static/css/cabinet.css` (секция `.semester-panel`), `templates/schedule/schedule.html` (только строка `.tl-grid`, шапки блока не трогались).

## 1. Штрих пунктира: 9px → 36px (ровно в 4 раза реже)

| Что | Было | Стало |
|---|---|---|
| Вертикальные направляющие `.tl-guides` | `linear-gradient(to bottom, var(--tl-guide) 0 4px, transparent 4px 9px)`, `background-size: 1.5px 9px` | `... transparent 4px 36px`, `background-size: 1.5px 36px` |
| Горизонтальные линии `.tl-gridline` | `repeating-linear-gradient(to right, var(--tl-guide) 0 4px, transparent 4px 9px)` | `... 0 4px, transparent 4px 36px` |
| Коннектор `.tl-row > .tl-subject::after` | `... 0 3px, transparent 3px 7px` (период 10) | `... 0 4px, transparent 4px 36px` (тот же ритм 4/36) |

Проверка по пикселям скриншота (`plan-paper-after.png`, 2 px/CSS, автокорреляция вдоль линии):
`x=209css → период 36.0 px, штрих 4.0 px`; `x=438css → 36.0 / 4.0`; `y=299css (горизонталь) → 36.0 / 4.0`.
До правки: `8.8–9.2 px`. 36 / 9 = 4.00.

## 2. Вертикали от левого края

| Что | Было | Стало |
|---|---|---|
| `.tl-guides` | `left: var(--tl-col)` (ось семестров) | `left: 0` (весь блок) |
| Позиции линий | `12.5% … 87.5%` от дорожки | `calc(var(--tl-col) ± (100% − var(--tl-col)) * k/8)`, k = −1 … 7 |
| Слой под названиями | — | первая линия — `var(--tl-guide-soft)` (чернила 40%), остальные — `var(--tl-guide)` (62%) |
| Текст поверх сетки | — | `.tl-row > .tl-subject { position: relative; z-index: 1 }` |

`top: calc(42px + 10px)` (высота оси + row-gap) сохранён — на подписи семестров линии не заходят.
На узком экране (`--tl-col: 150px`) линия под названиями садится на 78.75 px, на край текста не наезжает.

## 3. Подсветка текущего семестра убрана

Удалены `--tl-now-band`, `--tl-guide-now`, `--tl-guide-now-soft`, правила
`.tl-grid.has-now .tl-guides::before` и `.tl-grid.has-now .tl-gridline::after`.
Из шаблона убраны класс `has-now` и переменная `--now`. Бейдж семестра в оси (`.tl-tick.is-now`: точка + акцентная цифра) оставлен.

## 4. Палитра отрезков

Причина «виден только бордер»: в старых правилах использовался `var(--aux)`, которого нет в токенах
(есть только `--brand-aux`), поэтому `background` у `.tl-seg--1/2/3` был невалиден → прозрачный.

Новая схема: заливки `--tl-seg-0…5` заданы в `.semester-panel` (светлые темы) и переопределены для
`[data-theme="surik"]` / `[data-theme="latun"]`; цифры — `color-mix(in oklab, var(--tl-seg-fill), var(--brand-ink) 24%)`.
