# Задача C — шапка при увеличении шрифта (a11y fs1/fs2)

## Что изменено

- `static/site/css/header.css` — только правила под `html.a11y-fs1` / `html.a11y-fs2`:
  - симметричные поля пилюли `padding-inline: clamp(14px, 2vw, 28px)`;
  - бренд занимает высоту строки 44px (зона нажатия, симметричные отступы сверху/снизу);
  - при `min-width: 1181px`: `align-items: center`, `align-content: center`,
    `justify-content: space-between`, `row-gap: 10px`, `padding-block: 16px`;
  - обе строки занимают одинаковую ширину: бренд+меню по краям первой,
    утилиты слева и «Личный кабинет» справа во второй;
  - `--head-h: 134px` = фактическая высота пилюли (2×44 + 10 + 2×16 + 2 рамка + 2 запас на `a11y-sp`).
- `scripts/build_static_site.py` — тот же CSS продублирован в `MOBILE_HEAD_CSS`
  (иначе генератор перезапишет `header.css`).

Базовый режим не тронут: `git diff` содержит только селекторы `html.a11y-fs1/fs2`.
Исходные `padding: 0 6px 0 18px` и однострочная шапка 56px сохранены.

прямоугольников, вертикальные центры элементов по строкам.

Дополнительно:

- вертикальные отступы пилюли на 1440 в fs1/fs2: 18px сверху и 18px снизу (по границам строк);
- на 1181 и 1200 px в fs1/fs2 обе строки имеют одинаковые границы (36.6…1144.4 и 37…1163) — строки не разъезжаются;
- свип 320–1920 × fs1/fs2: `scrollWidth == innerWidth`, пересечений 0, зазоры равны, высота совпадает с `--head-h`;
- контент под шапкой (верх h1): 1440/fs2 — 190.6px запаса, 1024/fs2 — 132.7px, 390/fs2 — 181.3px (в base тоже положительный).

Базовый режим: зазоры 19/7 — это исходное значение (`padding: 0 6px 0 18px`),
сохранено намеренно по требованию «базовый режим без визуальных изменений».
В fs1/fs2 разница зазоров 0 (≤2px).

Пиксельный контроль скриншота 1440/fs2: красный логотип начинается на x=129,
красная кнопка «Личный кабинет» заканчивается на x=1310, границы пилюли —
x=100 и x=1340, то есть 29px слева и 30px справа (разница 1px, допуск ≤2px).

Проверен пользовательский путь: клик «Доступность» → «А++» даёт `html.a11y-fs2`,
пилюля 134px, `--head-h: 134px`, без горизонтального скролла; после перезагрузки настройка сохраняется.
